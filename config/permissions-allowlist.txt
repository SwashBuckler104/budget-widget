# Every permission the built APK may request (SCOPE.md §7). scripts/check-permissions.sh fails
# on anything else. Adding a line is a reviewed, deliberate change: give the reason next to it.
# ${applicationId} is replaced with the APK's package name.

# androidx.core: protects receivers registered with RECEIVER_NOT_EXPORTED on API < 33.
${applicationId}.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION

# SCOPE.md F2: the real-time receiver and the inbox reconcile/backfill scan. Runtime-granted.
android.permission.RECEIVE_SMS
android.permission.READ_SMS

# WorkManager (ADR-0013). Expedited ingest work runs as a foreground service on API 26-30.
android.permission.FOREGROUND_SERVICE
# WorkManager holds short wake locks while workers run. Normal permission, no user data.
android.permission.WAKE_LOCK
