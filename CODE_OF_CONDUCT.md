# Code of conduct

Budget Widget follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good faith, welcome newcomers, and keep discussion
about the work. Harassment, insults, and publishing other people's private information (including
unredacted SMS) are not acceptable.

## Reporting

Report unacceptable behavior to the maintainer, [SwashBuckler104](https://github.com/SwashBuckler104),
through a private message on GitHub or a
[private security advisory](https://github.com/SwashBuckler104/budget-widget/security/advisories/new)
if it needs confidentiality. Reports are handled privately. The maintainer may remove content or
block contributors who break this code, following the Covenant's enforcement guidelines.
